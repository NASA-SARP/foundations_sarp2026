# Foundations Lessons SARP 2026

This repository holds the content for the SARP 2026 Foundations lessons track. This set of lessons gives an introduction to using Python for Earth Science data processing. Topics covered include:

| Lesson | Topic |
| -- | -- |
| 1 | Data types and variables |
| 2 | Lists and dictionaries |
| 3 | xarray Data structures |
| 4 | Advancing computations |
| 5 | Data exploration |
| 6 | Flex time |
| 7 | Data visualization |
